# Mafia Game
Web version of the classic board game "Mafia", implemented with React + TypeScript + Redux Toolkit. Future updates are planned.

## Tech Stack
- React
- TypeScript
- Redux Toolkit
- Vite
- SCSS

## Getting Started

\`\`\`bash
npm install
npm run dev
\`\`\`
